# Decision-page testing evidence

The HTML and screenshots are generated by the shipped renderer using isolated fixture tasks created with `fm-captain-hold.sh hold`.
The pages retain the project's existing design and contain no manually recreated UI.

`decision-flow.txt` records the actual hold, completion, snapshot, composition and rendering outputs.
The rosé call was completed with a draft link, then its own status recorded the final link without another completion.
Both rendered pages link to final.
A separate call with no link of its own remains marked “pas de page dédiée” even though its origin's status contains a sibling's page.
An unmatched call remains visible under Cerveau.

`browser-check.mjs` loads these generated pages in real Chrome, clicks two choices, selects two calls, and clicks the grouped page-creation button.
`browser-results.json` records the resulting three queued prompts, their routing data, zero send calls, and four remaining decisions on each page.
The Lavish API is instrumented in memory for this browser check; no live Lavish session is created and no message is sent.
Screenshots show the actual page UI before and after those interactions, at desktop and 390-pixel phone widths.
Standalone HTML has no Lavish queue, so its buttons correctly require opening in Lavish to queue anything.

The existing targeted suites separately exercise queue refusal, changing a choice, single and multiple selection, both stable HTTP addresses, oldest-first grouping, partial-data empty states, own-call link ownership, newest-link persistence, title-preserving retries, IPv6 URLs, and lock ordering.
The opt-in Chrome suite checks folded and unfolded phone geometry and the visible stable-address fallback.

An initial lifecycle-test setup used a temporary root inside the repository.
The second-home fixture was correctly rejected because a managed home cannot be inside the source repository.
The check was rerun using the suite's normal self-cleaning system temporary root, allowed as an incidental test-toolchain write.
No source or test changes were retained.

The final regression check temporarily restored persisted-links-first ordering at each same-call merge, one at a time. Both public snapshot interfaces selected draft with the old order and final with the fix. The original source bytes were restored after each check; the restored outputs matched the fixed outputs. See `link-regression-results.json`.
